A program that writes one one-line joke about working beside an AI coding
agent. The joke it writes:

> My agent's commit for the demo fix says just 'fixed' — 412 files changed,
> nothing explained, confidence: absolute.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# -> out/entry.txt (the joke, UTF-8, 114 characters)
```

Deterministic, no network, Python 3 standard library only.
